# 功能成熟度

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

某些 ChatGPT 和 Codex 功能附带成熟度标签，因此您可以了解每个功能的可靠性、可能发生的变化以及期望的支持级别。

| 到期日 | 含义 | 指导 |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 正在开发 | 尚未准备好使用。                                                                                            | 请勿使用。                                                                    |
| 实验性 | 不稳定，OpenAI 可能会删除或更改它。                                                                  | 使用风险自负。                                                         |
| Beta | 准备进行广泛测试；在大多数方面都已完成，但某些方面可能会根据用户反馈进行更改。       | 适用于大多数评估和飞行员；期待小的变化。                      |
| 稳定 | 完全支持、有文档记录，可供广泛使用；行为和配置随着时间的推移保持一致。 | 适合生产使用；删除通常会经历一个弃用过程。 |
| 已弃用 | 仍可用于兼容性，但不再推荐； OpenAI 可能会在未来版本中删除它。       | 避免新的使用并计划迁移。                                            |
