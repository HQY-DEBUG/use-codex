# 运行环境选择

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

在 ChatGPT 桌面应用程序中，打开 ChatGPT 下拉列表并选择 **Codex**。启动 Codex 聊天时，选择其运行位置：

- **本地**：直接在当前项目目录中工作。
- **工作树**：隔离 Git 工作树中的更改。 [了解更多](git-worktrees.zh-CN.md)。
- **云**：在配置的云环境中远程运行。

**本地** 和 **工作树** 聊天都在您的计算机上运行。

如需完整的术语表和概念，请浏览 [概念部分](../prompting.zh-CN.md)。
