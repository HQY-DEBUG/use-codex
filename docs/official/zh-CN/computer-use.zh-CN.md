# 电脑操作

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

在受支持的区域中，ChatGPT 桌面应用程序中的计算机使用可通过 ChatGPT Work 和 Codex 在 macOS 和 Windows 上使用。安装计算机使用插件。在 macOS 上，出现提示时授予屏幕录制和辅助功能权限。

通过计算机使用，ChatGPT 可以在 macOS 或 Windows 上查看和操作图形用户界面。将其用于命令行工具或结构化集成不足以完成的任务，例如检查桌面应用程序、使用浏览器、更改应用程序设置、使用无法作为插件使用的数据源，或者重现仅在图形用户界面中发生的错误。

由于计算机使用可能会影响项目工作区之外的应用程序和系统状态，因此请将其用于范围内的任务并在继续之前查看权限提示。

<a id="set-up-computer-use"></a>

## 设置计算机使用

在 ChatGPT 桌面应用程序中，选择 ChatGPT 并切换到切换器中的“工作”，或选择 Codex。打开 **插件 > 计算机使用** 并根据提示选择 **安装插件**。如果 ChatGPT 显示 **启用**，请选择它。打开计算机使用服务器和技能开关，然后选择 **立即尝试** 启动。



> 插图：计算机使用插件控件并启用 MCP 服务器和技能。



然后打开 **设置 > 计算机使用** 以检查应用程序访问权限。连接的浏览器控件显示 **管理** 操作。您批准用于未来任务的应用程序将显示在 **始终允许的应用程序** 部分。



> 插图：计算机使用设置显示应用程序控件和计算器是唯一始终允许的应用程序。



在 Windows 上，任务运行时使目标应用程序在活动桌面上可见。在 macOS 上，出现提示时授予屏幕录制和辅助功能权限，以便 ChatGPT 可以查看目标应用程序并与之交互。

在 macOS 上，授予：

- **屏幕录制** 权限，以便 ChatGPT 可以看到目标应用程序。
- **无障碍** 权限，以便 ChatGPT 可以单击、键入和导航。

<a id="when-to-use-computer-use"></a>

## 何时使用计算机

对于依赖屏幕截图或视觉判断的困难任务，请在模型选择器中提供 [GPT-6 阿斯特拉](models.zh-CN.md#gpt-6-astra) 时选择它。适用相同的插件设置、操作系统权限和应用程序访问控制。

当任务依赖于图形用户界面且难以仅通过文件或命令输出进行验证时，请选择“计算机使用”。

良好的配合包括：

- 测试 macOS 应用程序、Windows 应用程序、iOS 模拟器流程或 ChatGPT 正在构建的其他桌面应用程序。
- 执行需要 Web 浏览器的任务。
- 重现仅出现在图形界面中的错误。
- 更改需要点击 UI 的应用程序设置。
- 检查应用程序或数据源中无法通过插件获得的信息。
- 在 macOS 上，在后台运行范围任务，同时您继续在其他地方工作。
- 执行跨越多个应用程序的工作流程。

对于您在本地构建的 Web 应用程序，请首先使用 [内置浏览器](browser.zh-CN.md)。

<a id="windows-foreground-use"></a>

### Windows 前台使用

在 Windows 上，“计算机使用”在活动桌面上运行。当您继续使用相同的 Windows 会话时，它无法在后台运行，因此 ChatGPT 可以在任务运行时移动指针、键入并接管前台。

对于在您离开时应继续执行的 Windows 任务，请保持 Windows 设备解锁并连接到互联网。使用手机中的 [远程控制](remote-connections.zh-CN.md) 检查进度或发送后续指令，或在 Windows 虚拟机内运行 ChatGPT 桌面应用程序，以便计算机使用接管虚拟机而不是主桌面。

<a id="start-a-computer-use-task"></a>

## 启动计算机使用任务

在提示中提及 `@Computer` 或 `@AppName`，或要求 ChatGPT 使用“计算机使用”。描述 ChatGPT 应运行的确切应用程序、窗口或流程。

```text
使用“计算机使用”打开应用程序，重现入门错误，并修复
导致它的最小代码路径。每次更改后，运行相同的 UI 流程
again.
```

```text
打开 @Chrome 并验证最新更改后检出目录页面是否仍然有效。
```

如果目标应用程序公开专用插件或 MCP 服务器，则更喜欢数据访问和可重复操作的结构化集成。当ChatGPT需要目视检查或操作应用程序时，选择计算机使用。

<a id="permissions-and-approvals"></a>

## 权限和批准

工作区管理员可以限制计算机用户可以访问哪些应用程序以及是否可以保存批准。参见 [托管浏览器和计算机使用控件](enterprise/managed-configuration.zh-CN.md#control-browser-and-computer-use)。

计算机使用的系统权限与 ChatGPT 中的应用程序批准是分开的。在 macOS 上，屏幕录制和辅助功能权限允许 ChatGPT 查看和操作应用程序。应用程序批准决定您允许 ChatGPT 使用哪些应用程序。文件读取、文件编辑和 shell 命令仍遵循任务的沙箱和审批设置。

通过计算机使用，ChatGPT 只能在您允许的应用程序中查看并执行操作。在执行任务期间，ChatGPT 会先请求您的许可，然后才能使用您计算机上的应用程序。您可以选择 **始终允许**，以便 ChatGPT 将来可以使用该应用程序而无需再次询问。您可以从 ChatGPT 桌面应用程序设置的 **电脑使用** 部分的 **始终允许** 列表中删除应用程序。


  

> 插图：计算机使用批准对话框请求访问计算器




ChatGPT 也可能在采取敏感或破坏性行动之前请求许可。

如果 ChatGPT 无法查看或控制应用程序，请打开 **系统设置 > 隐私和安全** 并在 macOS 上检查 **屏幕录制** 和 **无障碍** 是否有 **Codex 电脑使用**。在 Windows 上，确保目标应用程序在活动桌面会话中可见。

<ToggleSection title="配置 Windows 应用程序策略">

在 Windows 上，计算机使用将持久应用程序决策存储在 `$CODEX_HOME/config.toml` 中。列出“计算机使用”可以在没有提示的情况下打开的应用程序：

```toml
[computer_use.windows]
always_allowed_app_ids = ["mspaint.exe"]
```

使用 Windows 计算机使用报告的应用标识符，例如桌面应用的可执行文件名称或打包应用的应用用户模型 ID。 ChatGPT 提示列表中没有的应用程序。要撤销已保存的决定，请从 **设置 > 计算机使用 > 始终允许** 中删除该应用程序。

该表存储本地计算机使用决策。它与管理员强制执行的 `requirements.toml` 是分开的，管理员可以通过 `[features].computer_use = false` 禁用计算机使用。旧的 `$CODEX_HOME/computer-use/config.toml` 允许列表条目迁移到当前设置；其 `denied` 列表不是当前策略架构的一部分。

</ToggleSection>

<a id="locked-use"></a>

## 锁定使用

锁定使用适用于 macOS。在 Windows 上，“计算机使用”在前台运行。

锁定使用允许 ChatGPT 在 Mac 锁定后使用计算机使用，但前提是您启用它。当 ChatGPT 任务需要在 Mac 锁定后使用连接设备上的桌面应用程序时，请使用它。

当您启用锁定使用时，ChatGPT 会安装参与 macOS 解锁流程的 Apple [授权插件](https://developer.apple.com/documentation/security/authorization-plug-ins)。

锁定用途有意缩小范围。它不是 Mac 的通用远程解锁路径，并且不允许其他应用程序或本地进程解锁计算机。

要使用锁定使用：

1. 在应用程序中打开 **设置 > 计算机使用**。
2. 启用锁定使用。
3. Mac 屏幕锁定后，从连接的设备启动使用“计算机使用”的任务。

当 ChatGPT 任务在 Mac 锁定后通过计算机使用访问应用程序时，ChatGPT 会暂时解锁 Mac，同时阻止本地使用并保留锁定的屏幕保护。在解锁之前，ChatGPT 会检查解锁尝试是否针对主动、可信的计算机使用回合。在这个短暂的窗口之外，ChatGPT 会拒绝解锁并要求您在需要时手动解锁。

锁定使用包括保障措施：

- 授权窗口是短暂的，并且范围仅限于当前的解锁尝试。
- 自动解锁仅适用于 ChatGPT 在计算机使用轮次期间。
- ChatGPT 覆盖所有显示器，同时桌面暂时解锁。
- 如果 ChatGPT 检测到本地键盘或指针输入，它会重新锁定 Mac 并暂停自动解锁，直到您手动解锁。

<a id="safety-guidance"></a>

## 安全指导

通过计算机使用，ChatGPT 可以查看屏幕内容、截取屏幕截图以及与目标应用程序中的窗口、菜单、键盘输入和剪贴板状态进行交互。将可见的应用程序内容、浏览器页面、屏幕截图和在目标应用程序中打开的文件视为任务运行时 ChatGPT 可能处理的上下文。

缩小任务范围并保留敏感流程：

- 一次给 ChatGPT 一个明确的目标应用程序或流程。
- 您可以随时停止任务或接管您的计算机。
- 保持敏感应用程序关闭，除非任务需要它们。
- 在 Windows 上，期望 ChatGPT 在工作时接管前台输入；使用辅助设备、虚拟机，或者在自己使用该桌面之前停止任务。
- 避免需要保密的任务，除非您在场并且可以批准每个步骤。
- 在允许 ChatGPT 使用应用程序之前，请查看应用程序权限提示。
- 仅将 **始终允许** 用于您信任 ChatGPT 在将来的任务中自动使用的应用程序。
- 保持帐户、安全、隐私、网络、支付或凭证相关设置的存在。
- 如果 ChatGPT 开始与错误的窗口交互，请取消任务。

如果 ChatGPT 使用您的浏览器，它可以与您已登录的页面进行交互。像您自己一样检查网站操作：网页可能包含恶意或误导性内容，网站可能会将批准的点击、表单提交和登录操作视为来自您的帐户。要在 ChatGPT 工作时继续使用您的浏览器，请要求 ChatGPT 使用其他浏览器。

该功能无法自动化终端应用程序或 ChatGPT 本身，因为自动化它们可能会绕过 ChatGPT 安全策略。它还无法以管理员身份进行身份验证，也无法批准您计算机上的安全和隐私权限提示。

文件编辑和 shell 命令仍然遵循 ChatGPT 批准和沙箱设置（如果适用）。通过桌面应用程序所做的更改可能不会显示在审阅窗格中，直到将其保存到磁盘并由项目跟踪。您的 ChatGPT 数据控制适用于通过 ChatGPT 处理的内容，包括“计算机使用”截取的屏幕截图。
