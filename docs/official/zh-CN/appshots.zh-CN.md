<a id="appshots"></a>

# 应用窗口快照

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

通过应用程序快照，您可以将最前面的应用程序窗口发送到 ChatGPT 中的聊天。当您正在计算机上的另一个应用程序中积极工作并希望向 ChatGPT 提供当前上下文以便它可以帮助您完成任务时，请使用它们。

Appshot 可在 macOS 上的 ChatGPT 桌面应用程序中使用。按两个 Command 键或您的自定义 Appshots 热键即可拍摄一张照片。

<a id="what-appshots-capture"></a>

## 应用程序快照捕获哪些内容

应用程序快照仅捕获最前面的窗口。它可以包括：

- 可见窗口的图像。
- 该窗口中的可用文本，包括可见文本和应用程序在可见滚动区域之外提供的文本。

将应用程序快照添加到聊天后，它的行为就像附件一样。 ChatGPT 将应用程序快照本地存储在会话文件中，例如您手动附加的文件或图像。

<a id="when-to-use-appshots"></a>

## 何时使用应用截图

当 ChatGPT 需要 Mac 应用程序的上下文才能执行操作时，请使用应用程序快照。

示例：

- 分享一个 API 参考页面并要求 ChatGPT 编写一个使用它的脚本。
- 共享电子邮件或日历视图，并要求 ChatGPT 起草下一步。
- 共享图像编辑器、设计或预览窗口，并要求 ChatGPT 修改相关资源或代码。
- 分享比描述更容易显示的错误、设置面板或应用状态。

<a id="take-an-appshot"></a>

## 拍摄应用截图

1. 将您要共享的应用程序窗口置于最前面。
2. 按两个命令键，或您在 ChatGPT 设置中配置的自定义热键。
3. 如果 ChatGPT 询问，则允许 macOS 权限。
4. 要求 ChatGPT 使用应用快照执行任务。



> 插图：ChatGPT 聊天编辑器，带有 Appshot 附件和后续提示



默认情况下，ChatGPT 为应用快照启动新的聊天。如果您在过去 60 秒内与聊天进行了交互，ChatGPT 会将应用快照添加到最近的聊天中。连续拍摄应用程序快照会将它们添加到同一个聊天中。

您可以在应用程序设置中更改 Appshots 热键。

<a id="permissions-and-safety"></a>

## 权限和安全

ChatGPT 可能会在拍摄应用程序快照之前请求权限：

- **屏幕和系统音频录制** 让 ChatGPT 捕获最前面窗口的图像。
- **无障碍** 允许 ChatGPT 从最前面的窗口读取可用文本。

拍摄应用程序快照与 ChatGPT 共享捕获的图像和可用文本。除非任务需要敏感内容，否则请避免拍摄敏感内容的应用程序快照。

查看应用程序快照的方式与查看与 ChatGPT 共享屏幕截图和文档的方式相同。

<a id="limits-and-troubleshooting"></a>

## 限制和故障排除

Appshot 可在 macOS 上的 ChatGPT 桌面应用程序中使用。如果您在 CLI 中恢复已包含应用程序快照的聊天，则附件将成为聊天历史记录的一部分，但 CLI 无法创建新的应用程序快照。

对于某些应用程序和网站，包括 Google 文档、Gmail、Google 表格和 Google 幻灯片，ChatGPT 可能仅收到可见的屏幕截图，而可能无法收到完整的文档或屏幕外文本。在ChatGPT Work或Codex中，ChatGPT可以使用匹配的已安装插件来访问相关的应用程序内容并帮助满足您的请求。

如果应用程序快照不起作用：

1. 打开**系统设置 > 隐私和安全**。
2. 检查 Codex 计算机使用的 **屏幕和系统音频录制** 和 **无障碍**。
3. 重新启动应用程序并重试。
