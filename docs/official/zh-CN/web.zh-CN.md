提出问题、研究主题或描述多步骤任务。 ChatGPT 可以使用您的文件和连接的工具来创建文档、演示文稿、电子表格和其他输出。

### 从这里开始

- [打开ChatGPT](https://chatgpt.com)
- [网络快速入门](#getting-started)

<a id="why-use-chatgpt-on-the-web"></a>

### 为什么在网页上使用ChatGPT

- **从一个明确的任务开始：** 给ChatGPT一个目标及其所需的背景，然后通过后续消息完善结果。
- **使用您的文件和工具：** 使用文件、项目和插件为 ChatGPT 提供任务所需的信息和工具。
- **创建您可以共享的文件：** 将研究和分析转化为文档、演示文稿、电子表格和其他成品。

## 开始使用

**开始使用网络。**

打开 ChatGPT，选择您想要的工作方式，并为其提供明确的结果及其所需的上下文。

<a id="1-open-chatgpt-and-sign-in"></a>

### 1.打开ChatGPT并登录

转到 [聊天网站](https://chatgpt.com) 并使用您的 ChatGPT 帐户登录。

<a id="2-select-work"></a>

### 2. 选择工作

选择 **工作** 进行研究、分析、文档、电子表格、演示文稿、站点和其他多步骤任务。对于答案或对话，请选择 **聊天**。

[了解如何使用 ChatGPT](use-chatgpt.zh-CN.md)

<a id="3-start-a-chat-or-choose-a-project"></a>

### 3. 开始聊天或选择项目

使用聊天来完成一次性任务。当您继续工作时，使用项目将相关的聊天、文件和说明保存在一起。

[了解聊天和项目](projects.zh-CN.md)

<a id="4-send-your-first-message"></a>

### 4. 发送您的第一条消息

描述您想要的结果并添加 ChatGPT 需要的任何文件或上下文。您可以通过后续消息来完善结果。

[探索示例用例](https://learn.chatgpt.com/use-cases)

## 查看您可以在网络上执行哪些操作

使用聊天来快速获得答案，或者使用处理文件、插件和推理设置来执行多步骤任务。

- [选择聊天或工作](use-chatgpt.zh-CN.md)：使用聊天来探索问题或形成想法。当您有明确的结果并希望 ChatGPT 计划、收集背景信息并执行更大的任务以获得可审查的结果时，请切换到工作。
- [选择正确的模型和推理](models.zh-CN.md)：从输入框中选择模型和推理级别。从默认工作量开始，然后在任务需要更深入的规划、分析或更大规模的多智能体运行时增加工作量。
- [引入工具和可重复的工作流程](skills-and-plugins.zh-CN.md)：安装插件以连接 Google Drive、GitHub 或 Slack 等服务。当 ChatGPT 应遵循特定工作流程、使用团队指导或以一致的方式完成工作时，请添加技能。
- [创建和完善完成的文件](artifacts-viewer.zh-CN.md)：使用 ChatGPT Work 从源材料创建文档、演示文稿、电子表格或 PDF。在聊天中查看结果，请求重点修改，并在准备好后下载完成的文件。

<a id="use-chatgpt-on-the-web-when"></a>

## 当……时在网络上使用 ChatGPT

- [您需要完成一个多步骤任务](#getting-started)：ChatGPT Work 可以规划任务、收集背景信息，并通过多个步骤朝着明确的结果迈进。
- [该任务需要更深入的推理](models.zh-CN.md)：选择更强大的模型或增加复杂规划和分析的推理工作。
- [这项工作取决于您的工具和环境](skills-and-plugins.zh-CN.md)：使用插件和技能引入连接的源、采取行动并遵循可重复的工作流程。
- [您需要一个可以查看和共享的文件](artifacts-viewer.zh-CN.md)：将源材料转换为文档、演示文稿、电子表格或 PDF，然后通过反馈对其进行完善。
