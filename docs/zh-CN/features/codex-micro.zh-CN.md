# Codex Micro 硬件

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

Codex Micro 是 Codex 与 Work Louder 之间的限量合作产品。它与 ChatGPT 桌面应用程序配合使用，让您可以快速查看聊天、在聊天之间跳转、使用语音输入以及触发常见操作或技能，而无需离开键盘。

<a id="set-up-codex-micro"></a>

## 设置Codex Micro

1. 打开 ChatGPT 桌面应用程序。
2. 按一下后部按钮即可打开 Codex Micro。
3. 使用 USB-C 电缆或 [与蓝牙配对](#pair-with-bluetooth) 连接它，然后按照 ChatGPT 检测到它时出现的设置进行操作。
4. 在 macOS 上，出现提示时允许 **输入监控**，以便 ChatGPT 可以响应按键。
5. 打开 **设置 > Codex 微型** 选择智能体键遵循或触发的内容，自定义命令键、模拟摇杆和拨号盘，以及调整灯光和语音控制。

默认情况下，按住转盘一小会儿即可打开这些设置。您还可以选择 ChatGPT 底部帐户名旁边的 Micro 图标。自定义拨号分配可以取代按住快捷键。

ChatGPT 首次检测到支持的 Micro 后，设备设置仍然可用。 ChatGPT 集成不需要大声工作输入。使用它来自定义其他应用程序的控件或配置更多层。

<a id="pair-with-bluetooth"></a>

## 与蓝牙配对

Codex Micro提供三个蓝牙通道。

1. 按一下后部按钮即可打开 Micro。
2. 按住左下边缘的触摸控件三秒钟。当蓝牙模式处于活动状态时，Micro 下方的灯光会变成蓝色。
3. 点击触摸控件可选择蓝牙通道 1、2 或 3。通道指示灯快速闪烁表示 Micro 已准备好配对。
4. 打开计算机的蓝牙设置并在 Micro 出现时连接到它。
5. 等待通道灯常亮，表示配对完成。

连接选择器在无输入五秒后关闭。要切换到另一个配对通道，请再次打开选择器，选择该通道，然后等待其关闭。要再次配对该通道，请按住触摸控件三秒钟，直到其指示灯开始闪烁。

要使用 USB-C，请打开连接选择器并点击触摸控制，直到 Micro 下方的指示灯变成白色。当 Micro 仍处于蓝牙模式时连接 USB-C 电缆可以为其充电，但不会将其切换到有线连接。

有关硬件图，请参阅 [大声工作 Codex Micro 设置指南](https://worklouder.cc/openai-micro-setup)。

## 使用智能体密钥读取和切换聊天

六个磨砂智能体键中的每一个都可以跟随聊天并点亮以显示其当前状态。按一次智能体键即可切换到该聊天，而无需将 ChatGPT 向前移动。在 350 毫秒内按两次可切换聊天并将 ChatGPT 窗口向前移动。要在第一次按下时对焦 ChatGPT，请在设备设置中打开 **单击聚焦 ChatGPT**。

| 指示灯 | 状态 | 含义 |
| ----- | ---------------- | ----------------------------------------- |
| 白色 | 空闲 | 聊天空闲。                         |
| 蓝色 | 思考 | ChatGPT 正在工作。                       |
| 绿色 | 已完成 | 聊天已完成，但有未读更新。 |
| 琥珀色 | 需要输入 | ChatGPT 需要您的批准或回复。  |
| 红色 | 错误 | 出现问题。                     |
| 关闭 | 未分配聊天 | 该键不跟随聊天。            |

所选聊天的按键会闪烁其状态指示灯。

开箱即用后，按键会跟随您最近更新的六个聊天记录，无论它们是否已固定。在设备设置中更改 **智能体密钥** 以使用不同的排列：

- **最近的聊天记录**：关注最近更新的六个聊天（固定或取消固定）。
- **固定聊天**：关注 **已固定** 中的前六个聊天。
- **优先聊天**：将等待输入的聊天、未读聊天和活动聊天放在前面。
- **自定义作业**：为每个智能体键分配聊天、快捷方式、物理键操作或启用的技能。按未分配的智能体键可打开新聊天。当您开始聊天时，ChatGPT 将其分配给该键。

聊天后按键的状态颜色保持不变。使用 **自定义作业**，智能体密钥可以触发操作。

## 使用和自定义命令键

Codex Micro 的默认布局有六个操作：



  


|                            按键 | 默认动作 |
| :-------------------------------------------------------: | ---------------------------------------- |
|  <CodexMicroTableKeycap keycapId="FAST" label="快" />   | 打开或关闭快速模式。                |
| <CodexMicroTableKeycap keycapId="APPR" label="批准" /> | 批准当前请求。             |
| <CodexMicroTableKeycap keycapId="REJ" label="拒绝" />  | 拒绝当前请求。             |
|  <CodexMicroTableKeycap keycapId="SPLIT" label="叉子" />  | 在新聊天中继续当前聊天。 |
|   <CodexMicroTableKeycap keycapId="MIC" label="麦克风" />    | 开始一键通。                      |
| <CodexMicroTableKeycap keycapId="CODEX" label="Codex" />  | 在编辑器中发送消息。        |

  

  


麦克风键使用计算机的麦克风。 Codex Micro 没有自己的麦克风。默认情况下，它使用 **一键通话**：说话时按住该键，然后松开即可停止。对于免提录音，在 350 毫秒内按两次可继续录音。再按一次即可停止。

录音时，海绿色的灯光会在键盘周围移动。当 ChatGPT 处理您的语音时，它会变成移动的白光，然后在提示准备好时变成稳定的白色。按Codex键发送。

如果 **麦克风键** 下有 **语音聊天**，请选择它以使用麦克风键开始语音聊天或切换麦克风；按住它可以结束聊天。打开**使用单独的麦克风键**可独立映射宽Mic键下的两个开关。

在设备设置中，在 **布局** 预览中选择命令键，然后选择其键帽和操作。您可以打开浏览器或终端、管理聊天、查看更改、运行 Git 和拉取请求操作、附加文件或照片、打开插件或计划任务、更改推理工作、运行启用的技能或分配其他快捷方式。如果您选择的键帽已在其他地方使用过，ChatGPT 会交换两个键帽，而不是使用一个键帽两次。

重新映射按键后，交换物理键帽以匹配其新操作。选择 **重置布局** 可恢复默认命令键和模拟摇杆分配，而无需更改智能体键模式或自定义聊天分配。

## 使用模拟摇杆和拨盘



  


模拟摇杆可以向任何方向自由移动。当您将其推离中心足够远时，ChatGPT 会将运动转变为四个方向动作之一。 Codex Micro 从此处显示的映射开始。

在设备设置中为每个方向选择任何可用的 ChatGPT 桌面命令或启用的技能。

  

  


| 方向 | 默认动作 |
| --------- | -------------------------- |
| 向上 | 打开或关闭计划模式。  |
| 右 | 在应用程序历史记录中前进。 |
| 向下 | 显示或隐藏侧边栏。  |
| 左 | 返回应用程序历史记录。    |

  




表盘默认使用**输入框导航**。转动它可以在输入框控件和选项之间移动，然后按下它可以打开或选择焦点控件。当输入框控件或菜单​​打开时，紧邻转盘右侧的智能体键会呈红色亮起。按该键取消。

在设备设置中选择四种拨号模式之一：

| 模式 | 行为 |
| -------------------------- | ------------------------------------------------------------------------------ |
| **输入框导航** | 在输入框控件中移动并选择焦点控件。                 |
| **仅推理** | 调整推理工作并打开其滑块或高级选项。               |
| **对话滚动** | 滚动当前聊天；按转盘可跳至最新消息。          |
| **自定义作业** | 将动作或技能分配给左转、右转、按下和长按。 |

按住转盘可在除**自定义作业**，它运行分配给长按的操作。

## Codex 微型故障排除

<a id="fix-input-monitoring-on-macos"></a>

### 修复 macOS 上的输入监控

如果设备设置显示未设置输入监控，请选择 **打开系统设置**，然后按照以下步骤操作：

1. 打开**系统设置 > 隐私和安全 > 输入监控**。
2. 如果 ChatGPT 已列出，请打开它的访问权限。如果缺少，请将 **ChatGPT** 从应用程序拖到列表中，或选择 **添加 (+)** 并选择 **ChatGPT**。
3. 退出并重新打开 ChatGPT，然后确认其在第 1 层检测到 Micro。

有关此 macOS 权限的更多信息，请参阅 [Apple 的输入监控指南](https://support.apple.com/guide/mac-help/mchl4cedafb6/mac)。

<a id="fix-connection-interference"></a>

### 修复连接干扰

当 ChatGPT 检测到 Micro 但无法连接或失去通信时，会自动重试。如果问题仍然存在，请重新连接 Micro 并检查键盘实用程序或安全工具是否阻止对其进行访问。

{/* vale Vale.Spelling = NO */}

在 macOS 上，Work Louder 指出，当 Karabiner 和 Logitech Options+ 拥有输入监控权限时，这些应用程序可能会干扰微通信。要测试干扰，请退出键盘实用程序或暂时关闭其输入监控访问，然后重新连接 Micro。如果您的组织管理您的计算机，请要求您的 IT 管理员检查设备规则。
