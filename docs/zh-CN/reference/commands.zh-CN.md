## 搜索过去的聊天记录并在聊天中查找

使用 **搜索聊天记录** 重新打开过去的聊天。搜索聊天没有默认快捷方式。您可以在 **设置 > 键盘快捷键** 下分配一个。当扩展匹配可用时，搜索还可以匹配聊天内容和 Git 分支名称，因此您可以从聊天或分支中搜索短语，例如 `fix/login-redirect`。

打开聊天后使用 **在聊天中查找** 查找其中的文本。它不会搜索其他聊天。

有关以 `/` 开头的操作，请参阅 [斜杠命令](https://learn.chatgpt.com/docs/reference/slash-commands)。

<a id="deep-links"></a>

## 深层链接

ChatGPT 桌面应用程序保留 `codex://` URL 方案以实现兼容性，因此链接可以直接打开应用程序的特定部分。在将查询字符串值添加到 URL 之前对其进行编码。

<a id="supported-links"></a>

### 支持的链接

创建链接时使用这些规范形式。以下部分按链接类型列出了完整参考。

| 深层链接 | 打开 |
| --------------------------------------------------------------------------- | ------------------------------------------------------- |
| `codex://threads/new` | 一个新的本地聊天。                                       |
| `法典：//new？<query>` | 至少具有一个查询参数的新本地聊天。     |
| `法典：//threads/<thread-id>`                                               | A local chat. `<thread-id>` 是其技术线程 ID。 |
| `codex://settings` | 设置。                                               |
| `法典：//settings/connections/<connection-type>` | 计算机、设备或 SSH 连接设置。           |
| `法典：//settings/connections/ssh/add？名称=<ssh-config-host>` | 将主机从 SSH 配置添加到 Codex。              |
| `codex://skills` | 技能。                                                 |
| `codex://automations` | 计划在创建流程打开时进行。                    |
| `法典：//plugins/install/<plugin-name>？市场=<marketplace-name>` | 来自已知市场的插件的安装流程。 |
| `法典：//plugins/<plugin-id>` | 插件详细信息页面。                                   |
| `法典：//plugins/<plugin-name>?市场路径=<absolute-marketplace-path>` | 来自本地市场的本地插件详细信息页面。    |
| `法典：//pets/install？名称=<pet-name>图片网址=<https-image-url>` | pet 安装流程。                                   |

### 聊天记录

当您需要打开现有的本地聊天或开始新的聊天时，请使用这些链接。

| 深层链接 | 打开 |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `法典：//threads/<thread-id>` | A local chat. `<thread-id>` 是其技术线程 ID。                                                      |
| `codex://threads/new` | 一个新的本地聊天。                                                                                            |
| `法典：//threads/new？<query>` | 带有可选查询参数的新本地聊天。                                                             |
| `法典：//new？<query>`         | A new local chat. Include at least one of `prompt`, `path`, or `originUrl`;否则该链接不会执行任何操作。 |

对于 `codex://threads/new` 或 `codex://new`，根据需要添加任意这些查询参数；您可以将它们组合在同一个 URL 中。

| 查询参数 | 必需 | 作用 |
| ---------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `提示=<text>` | 否 | 设置初始输入框文本。                                                                                                                               |
| `路径=<absolute-path>`       | No       | Opens the new chat in a local workspace. `path` 必须是本地目录的绝对路径。有效时，Codex 使用该目录作为活动工作区。 |
| `originUrl=<git-remote-url>` | No       | Matches one of your current workspace roots by Git remote URL. If `path` is also present, Codex resolves `path`首先。                                        |

示例：[显示一些有关我如何使用 Codex 的有趣统计数据](codex://threads/new?prompt=Show%20me%20some%20fun%20stats%20about%20how%20I%27ve%20been%20using%20Codex)

<a id="start-a-task-with-a-plugin"></a>

<a id="start-a-chat-with-a-plugin"></a>

#### 使用插件开始聊天

为了帮助用户开始插件支持的聊天，请在编码之前在提示中包含插件提及：

```text
[@Example](plugin://example@openai-curated) Summarize this document: https://example.com/document/123
```

将完整提示编码为 URI 组件（例如，在 JavaScript 中使用 `encodeURIComponent`）并将其传递给 `prompt` 参数：

```text
codex://new?prompt=%5B%40Example%5D(plugin%3A%2F%2Fexample%40openai-curated)%20Summarize%20this%20document%3A%20https%3A%2F%2Fexample.com%2Fdocument%2F123
```

该链接将打开一个新的聊天，其中包含编辑器中已解码的提示。它不会自动发送提示。用户发送后，Codex 可以在该聊天中使用已安装的插件。如果该插件未安装但可供用户使用，Codex 会要求用户安装它并连接任何所需的连接器。设置后，用户可以选择 **继续** 恢复相同的聊天。工作区设置可以限制用户可以安装的插件。插件安装和权限详细信息，请参见[插件](../plugins.zh-CN.md)。

### 插件

插件链接使用不同的形式，具体取决于您是从市场安装、打开插件还是从本地 `marketplace.json` 工作。有关插件基础知识，请参阅 [插件](../plugins.zh-CN.md)。有关本地或回购市场设置，请参阅 [构建插件](https://developers.openai.com/plugins/build/plugins#build-your-own-curated-plugin-list)。

<a id="plugin-install"></a>

#### 插件安装

使用此表单打开 Codex 已了解的市场中插件的安装流程。

| 深层链接 | 打开 |
| ---------------------------------------------------------------------- | ----------------------------------------------- |
| `法典：//plugins/install/<plugin-name>？市场=<marketplace-name>` | 插件详细信息或插件的安装流程。 |

| 查询参数 | 必需 | 作用 |

<a id="plugin-detail"></a>

#### 插件详情

| 深层链接 | 打开 |
| ----------------------------- | --------------------- |
| `法典：//plugins/<plugin-id>` | 插件详细信息页面。 |

`<plugin-id>` must identify the plugin. For an OpenAI-curated plugin, use the form `<plugin-name>@openai-curated`。

Codex 生成的插件链接也可以包含这些查询参数。当您手动编写链接时，请忽略两者。

| 查询参数 | 必需 | 作用 |
| ------------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `主机ID=<host-id>` | No       | Identifies the Codex host that owns the plugin context, such as `local` 或您配置的远程连接之一。 Codex 提供这些 ID。 |
| `source=manage` | 否 | 保留应用程序的插件管理入口点。它不仅仅是管理员。                                                                         |

<a id="pets"></a>

### 宠物

启用该功能后，使用这些链接打开 pet 安装流程。

| 深层链接 | 打开 |
| ----------------------------------------------------------------- | --------------------- |
| `法典：//pets/install？名称=<pet-name>图片网址=<https-image-url>` | pet 安装流程。 |

| 查询参数 | 必需 | 作用 |
| ------------------------------ | -------- | ------------------------------------------------------------------------------------------- |
| `名称=<pet-name>` | 是 | 设置宠物名称。该值必须至少包含一个非空白字符。            |

安装链接仅接受这些查询参数。无效的名称、非 HTTPS 图像 URL、不受支持的精灵版本或额外的路径段会导致链接不执行任何操作。
