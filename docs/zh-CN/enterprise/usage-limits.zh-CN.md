# 用量上限与支出控制

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

ChatGPT 工作区使用限制和支出控制适用于工作区计划下的合格活动。根据计划，这可能包括一些 Codex 活动。这些控件不是通用的 Codex 限制系统，也不管理 OpenAI API 平台计费。

有关完整的管理模型，请参阅 [角色和工作区权限](roles-and-workspace-permissions.zh-CN.md)。

<a id="know-when-these-controls-apply"></a>

## 了解这些控制措施何时适用

在以下情况下查看 ChatGPT 工作区使用控制：

- 组织的协议使用共享或购买的 ChatGPT 工作区额度。
- 符合条件的 Codex 活动可以消耗这些额度。
- 管理员需要当前计划支持的用户护栏、工作区级别支出控制或使用通知。

使用控制不会配置功能权利或权限，但耗尽限制可能会暂停对合格功能的访问。它们不会影响源系统权限或管理平台 API 使用或计费。
