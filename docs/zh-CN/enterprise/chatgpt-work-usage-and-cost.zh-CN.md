# Work 用量与成本

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

ChatGPT Work 帮助员工完成多步骤任务，例如研究主题、分析信息或创建完成的文档或演示文稿。完成这些任务可能需要额外的推理、工具和处理，这可能会消耗额度。该使用情况是否会影响您的发票取决于您的剩余额度、合同费率和工作区超额设置。

使用本指南了解工作如何影响使用情况、规划员工采用情况以及应用组织可用的支出控制。

<a id="usage-and-cost-at-a-glance"></a>

## 使用情况和成本一目了然

- 对于符合资格的基于额度的协议，工作活动从共享的工作区额度池中提取。
- 消耗承诺额度与产生新的发票费用不同。
- 员工可以同时使用聊天和工作；在估计采用时评估它们的综合合格使用情况。
- 基于角色的估算支持规划，但不是固定的每用户价格或保证的计费金额。
- 用户使用限制和工作区超额限制是单独的控制。警报提供通知，但不会停止支出。
- 使用组织观察到的使用情况和可衡量的工作流程结果来评估部署。

<a id="why-work-uses-credits"></a>

## 为什么 Work 使用额度

对于具有基于额度的协议的组织，符合条件的工作活动会消耗共享工作区分配中的额度。其他符合条件的 ChatGPT 功能可以从相同的分配中提取，因此工作不一定有单独的余额。

消耗量随以下情况变化：

- 模型、执行环境以及适用的推理或速度设置。
- 任务的复杂性以及所使用的任何符合条件的工具或功能，例如，使用 CRM 记录、文档或来自员工有权访问的已批准应用程序和系统的消息来准备季度业务审查。
- 员工执行任务的频率。

员工开始使用 Work 时无需停止使用 Chat。要了解总消耗量的变化，请将相同员工之前的聊天使用情况与可比较时期内的聊天和工作综合使用情况进行比较。

您的协议和适用的价目表决定了每项符合条件的活动消耗的额度。现有订阅费或席位费与消耗额度的估计是分开的。

<a id="understand-tokens-and-credits"></a>

### 了解Token和额度

**Token** 测量模型读取和写入的信息，包括输入、缓存输入和输出。根据基于额度的协议，**额度** 从共享工作区分配中支付符合条件的使用费用。有关额度定价，请参阅 [Token利率](../pricing.zh-CN.md#token-rates)。

如果您的企业协议指定以美元为单位按使用情况计费，请使用 [企业美元价目表](https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing) 和您的协议。请勿将额度计算应用于按美元计费的工作区，也不要将消耗的额度视为额外的发票费用。

<a id="when-usage-affects-your-bill"></a>

## 当使用情况影响您的账单时

符合条件的工作使用是否会产生额外费用取决于您的协议、剩余额度和适用的计费设置。使用承诺额度会减少您的可用余额，但其本身不会产生新的发票费用：

- **承诺的额度仍然存在：** 符合条件的活动会减少可用的额度分配。使用这些额度本身不会产生超出您现有协议的新费用。
- **没有剩余额度并且您的帐户允许超额：** 符合资格的使用可以在配置的工作区超额限制内继续，并且可能会按照合同规定的超额费率产生费用。
- **没有剩余额度，并且您的帐户不允许超额：** 符合资格的功能可以暂停，直到额度可用或适用的限制发生变化。

超额行为取决于帐户资格和配置的工作区限制。如果您的协议不允许超额，则当没有剩余可用额度时，符合资格的使用将停止。如果您的帐户允许超额，则未设置的限额可以允许超出额度余额的合格使用。在支持的情况下，超额限制为零可防止工作区继续超额，而 **无限制** 不是零支出上限。

使用报告和费用估算是计划或监控工具，而不是开具的发票。一些显示的估算使用合同规定的超额费率，该费率可能与承诺额度的费率不同。根据发票、计费周期和组织协议中的条款确认实际费用。

<a id="estimate-usage-for-a-role-or-team"></a>

## 估计角色或团队的使用情况

基于角色的估计可以帮助规划具有类似职责（例如财务、营销或销售）的员工的采用。从您的组织希望支持的员工和工作流程开始。

进行估算：

1. 确定建议的用户组和现有聊天活动的可比较时期。
2. 使用观察到的试点使用情况或经批准的、基于相关角色的基准来估计聊天和工作的综合消耗。
3. 检查剩余的承诺额度余额。对承诺的额度和任何超额部分分别应用适当的合同费率。
4. 确定预计使用量是否保持在可用额度范围内，或者是否可以达到合同规定的超额条款。
5. 使用实际采用情况、任务组合和观察到的消耗来更新估计。

批准的基准可以反映观察到的企业客户使用情况和实际使用的模型组合。其有用性取决于比较期、角色分类、工作流程和帐户假设。基于角色的广泛估计并不能建立特定于行业或特定于任务的基准。

**年化消费信贷估计** 项目观察了一年的使用价值。它不是单独的工作许可证价格、标准的每用户费用、OpenAI 的基础设施成本，也不是您的发票将增加相同金额的预测。实际增量费用取决于剩余承诺额度、合同定价、允许的超额和计费周期。

<a id="illustrative-marketing-planning-example"></a>

### 营销策划示例

对营销领域首次采用企业工作的观察分析显示，年消费信用值发生了以下变化：

- **中位数：** 大约为 **每名员工每年 53 美元**。
- **第 90 个百分位：** 大约为 **每名员工每年 1,154 美元**。
- **平均：** 大约为 **每名员工每年 309 美元**。

中位数代表观察到的个人使用情况的中点。平均数较高是因为较少数量的员工消耗较多的额度。第 90 个百分位数描述了观察到的较高使用阈值，而不是支出上限或最高限额。

对于具有类似用途组合的 **100名员工**，应用 **每位员工平均 309 美元** 大约代表 **每年 30,900 美元** 或 **每月 2,575 美元作为计划等值**。

这些定向估计反映了观察到的企业客户使用情况及其实际模型组合，根据一周的采用期使用情况进行年化。他们不保证节省费用、固定的每用户价格、自动账单或保证增加您的发票。实际费用取决于剩余的承诺额度、合同费率和允许的超额。

您的客户团队可以根据您组织的协议帮助解释批准的估算。

<a id="administrator-controls-and-reporting"></a>

## 管理员控制和报告

工作区所有者和管理员可以使用支持的设置来管理访问权限和符合条件的基于信用的使用：

- **工作访问：** 选择哪些人员或组可以通过工作区可用的权限访问工作。
- **模型及速度设置：** 如果可用，请在工作区设置 > 模型中配置起始工作和 Codex 模型、推理级别、速度和快速模式可用性。快速模式可能会为支持的模型消耗更多额度。
- **用户使用限制：** 设置受支持的每月工作区默认值、组限制或个人覆盖，以管理每个用户的合格使用情况。
- **工作区超额限制：** 控制共享信用分配用完后可以继续使用多少合格使用量。
- **使用提醒：** 在“计费”中，配置可用的使用阈值和支持的收件人。警报通知；他们不会停止消费。
- **额度余额和报告：** 在“账单”中，查看剩余额度并下载您的角色可用的使用情况报告。如果您的协议包含承诺额度，请将观察到的使用情况与合同分配和计费周期进行比较，以评估进度。
- **发票：** 当您的工作区角色包括发票访问权限时，查看已开具的发票和相应的计费周期。

个人用户覆盖优先于组和工作区默认值。当一个人属于多个群体时，适用最高的适用群体限制。没有配置限制的组不会施加零信用上限。检查每个试点参与者的有效限额。

使用限制不会增加额度或决定谁可以访问工作。模型默认值或员工指导可以影响消耗，但都不能取代强制使用限制或工作区超额设置。

控制可用性、报告详细信息、发票访问和计费行为取决于您的计划、工作区配置和协议。报告可能不会立即反映活动；在将使用情况与发票进行核对之前，比较报告时间戳和计费周期。有关跨产品适用性和当前设置过程，请参阅 [ChatGPT 使用限制和支出控制](usage-limits.zh-CN.md)。

<a id="measure-usage-alongside-outcomes"></a>

## 衡量使用情况和结果

选择具有明确现有基线的重复工作流程，例如客户研究、会议准备或财务报告。使用适合工作的访问、工具和模型功能，而不是假设每项任务都需要最高级的选项。

在试点期间，比较引入“工作”之前和之后的相同工作流程。根据任务的不同，您的组织可能会衡量：

- 完成工作所需的时间。
- 输出质量、完整性或一致性。
- 返工、手动协调或错误率。
- 团队是否完成了预期的交付成果。

审查这些客户测量的结果以及观察到的信用消耗和任何实际的计费影响。仅使用并不能节省成本，预计的时间改进也不能保证财务回报。

<a id="start-with-a-controlled-rollout"></a>

## 从受控的推出开始

扩展访问权限之前：

1. 确认您的协议、剩余额度、适用费率和超额设置。
2. 选择您的组织可以评估的有限组和工作流程。
3. 配置支持的访问权限、用户限制、警报和工作区超额限制。
4. 将聊天和工作的组合消耗量与组的现有基准进行比较。
5. 在扩大部署之前，请检查观察到的结果和任何实际的计费影响。

有关更广泛的访问、数据、治理和部署指南，请参阅 [ChatGPT Work 管理员常见问题解答](work-admin-faq.zh-CN.md)。有关特定于合同的定价、信用可用性和发票问题，请联系您的客户团队。
