# ChatGPT 桌面应用

> 有关完整的文档索引，请参阅 [llms.txt](https://learn.chatgpt.com/llms.txt)。通过将 `.md` 附加到页面 URL 即可获得文档页面的 Markdown 版本。

<a id="your-command-center-for-complex-work"></a>

## 您的复杂工作指挥中心

并行运行项目、处理文件、使用计算机以及从一个桌面工作区转移长时间运行的工作。

<a id="why-use-the-desktop-app"></a>

### 为什么使用桌面应用程序

- **让每一次聊天都清晰可见：** 在项目和长时间运行的工作之间移动而不会丢失上下文。
- **创建并检查实际输出：** 在同一工作区中打开文档、电子表格、图像和其他文件。
- **使用您的工具进行工作：** 使用浏览器、桌面应用程序和插件，或在聊天中安排任务。

<a id="get-started-with-the-desktop-app"></a>

## 开始使用桌面应用程序

安装 ChatGPT，登录，选择工作地点，然后发送您的第一条消息。

1. **安装 ChatGPT 桌面应用程序。** [下载ChatGPT](https://chatgpt.com/download/) 适用于 macOS 或 Windows，或遵循 [Linux安装指南](linux/linux-app.zh-CN.md)。
2. **打开ChatGPT并登录。** 打开应用程序，然后使用您的 ChatGPT 帐户登录。
3. **选择工作地点。** 开始聊天、创建项目或打开文件夹。 ChatGPT 可以使用您选择的位置中的文件和上下文。 [了解聊天和项目](projects.zh-CN.md)。
4. **发送您的第一条消息。** 选择 ChatGPT 或 Codex。在 ChatGPT 中，使用编辑器上方的开关选择“聊天”或“工作”。在 Codex 中，从新聊天开始。如需快速提问，请指向“新聊天”并选择右侧的“快速聊天”图标。然后描述您想要的结果并添加 ChatGPT 需要的任何文件或上下文。 [了解如何使用 ChatGPT](use-chatgpt.zh-CN.md)。

## 看看该应用程序可以做什么

将日常工作转化为可审查、改进和共享的成果。

- [以重点工作简介开始每一天](https://learn.chatgpt.com/use-cases/daily-work-brief)：查看日历、消息、电子邮件和项目上下文中的优先级。
- [分析文件并创建交互式视觉效果](https://learn.chatgpt.com/use-cases/analyze-data-export)：将数据导出转变为可以检查和共享的结果。
- [将分散的上下文转化为完整的 PRD](https://learn.chatgpt.com/use-cases/draft-prds-from-sources)：将来源汇集在一起，综合它们，并创建一个工作文档。
- [清理并准备杂乱的数据](https://learn.chatgpt.com/use-cases/clean-messy-data)：将杂乱的 CSV 或电子表格转换为干净的副本，而不更改原始文件。
- [将反馈转化为行动](https://learn.chatgpt.com/use-cases/feedback-synthesis)：将多个来源的反馈合成为可审查的工件。

- [创建和审查文件](artifacts-viewer.zh-CN.md)：构建完成的作品并在不离开ChatGPT的情况下检查它。
- [使用浏览器和您的计算机](computer-use.zh-CN.md)：授予 ChatGPT 任务所需工具的访问权限。
- [安排重复性工作](automations.zh-CN.md#schedule-a-task-inside-a-chat)：创建独立的计划任务或在现有聊天中安排任务。
