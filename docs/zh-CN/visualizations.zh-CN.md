<a id="check-availability"></a>

## 检查空房情况

| Surface | 当前可用性 |
| --------------------------- | ----------------------------------------------------------------------------- |
| 网络上的 ChatGPT | 可用于聊天中支持的帐户和 ChatGPT Work |
| ChatGPT 桌面应用程序 | 预览版推出 |
| ChatGPT 移动应用程序 | 向符合条件的账户推出； Composer 控件可能因应用程序版本而异 |
| Codex CLI 和 IDE 扩展 | 不支持可视化渲染 |

**可视化** 建议是您的帐户已启用预览的可靠标志。在推出期间，即使在同一计划中，可用性也可能因帐户、工作区和应用程序版本而异。

<a id="choose-when-a-visualization-helps"></a>

## 选择可视化何时有帮助

当视觉格式显着改善答案时，ChatGPT 可以选择视觉格式。当您特别想要交互式结果时，您还可以标记 `@Visualize`。

询问适合该工作的最小格式：

- 使用图表来标记关系或流程。
- 使用图表或绘图来表示命名的数字数据和比较。
- 使用地图获取地理信息。
- 当输入、时间、运动或空间关系发生变化时，使用交互式可视化。
- 当您需要具有可共享 URL、权限或持久数据的持久托管应用程序时，请使用 [网站](sites.zh-CN.md)。

<a id="prompt-with-an-outcome-and-controls"></a>

## 提示结果和控制

强烈的请求会列出结果、来源材料、问题和有用的互动。试试这个例子：



**提示：**

```text
@可视化供需如何决定市场价格。让我移动每条曲线，标记均衡，并解释价格和数量如何变化。
```

告诉 ChatGPT 要使用哪些信息，例如聊天中已有的内容、粘贴的数据、附件或可用的连接源。对于复杂的请求，请在可用时选择更高的推理设置。

<a id="refine-and-continue"></a>

## 完善并继续

继续同一个聊天并描述您想要的更改。有用的后续行动包括：

- 添加或删除控件、过滤器、比较或注释。
- 更正源数据、单位、标签或假设。
- 通过聚合、分箱或采样数据来简化缓慢的结果。
- 添加简洁的文本摘要和数据表。
- 使每个控制键盘都可访问并添加可见的焦点状态。
- 使用标签或图案以及颜色，并消除循环运动。
- 当需要托管和重新访问时，将结果转换为站点。

后续人员可以创建替换可视化，而不是就地编辑原始结果。在依赖新版本之前先查看它。

<a id="share-or-reuse-a-result"></a>

## 共享或重复使用结果

在可用时使用聊天的标准 **分享** 操作。首先查看整个共享聊天，包括其源数据和早期消息。可视化通常是 ChatGPT 创建时可用信息的快照，而不是与连接的源保持同步的实时仪表板。

生成的下载控件和导出格式可能因结果而异。如果导出不起作用，请向 ChatGPT 询问更简单格式的基础数据，或要求其将可视化转换为站点。

<a id="improve-accessibility"></a>

## 提高可达性

生成的可视化旨在使用语义控制、可见焦点、可读对比度和减少运动，但结果可能会有所不同。在共享之前检查可视化。要求 ChatGPT 添加文本摘要和数据表、标记轴和单位，避免单独依赖颜色，并使控件通过键盘工作。

<a id="recover-from-a-failed-result"></a>

## 从失败的结果中恢复

可视化可能需要一分钟或更长时间才能生成。如果结果为空或缺失，请等待响应完成，重新加载聊天一次，然后重试。如果仍然失败：

- 要求更小或更简单的可视化。
- 在大型数据集中聚合或合并数据、采样更少的点或降低精度。
- 删除生成的不起作用的控件或库。
- 验证重要值、地理边界和来源假设。
- 要求提供图表、图表、表格或网站。

使用与任何 ChatGPT 聊天相同的数据处理判断。仅当您的组织允许时才包含敏感信息，并在共享之前查看完整的聊天内容。
