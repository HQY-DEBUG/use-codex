# Codex 学习指南：基础知识

资料快照日期：2026-09-11。本文件是英文学习指南的中文译版；英文指南为独立编写的学习摘要，并非官方文档全文。本文件也不是官网的逐字全译。下载的官方英文资料见[本地原文索引](en/INDEX.md)。

## 1. 提示词（Prompting）

说明期望结果，提供相关材料，明确交付形式和重要限制。代码任务还应说明如何验证成功。用后续消息逐步改进结果；Steer 用来调整进行中的工作，Queue 用来安排之后执行的请求。可以先完成一个小任务，检查结果后再扩大范围。[官方来源](https://learn.chatgpt.com/docs/prompting) · [中文全文](zh-CN/prompting.zh-CN.md) · [英文原文](en/prompting.md)

## 2. 个性化（Personalization）

个人指令适合长期偏好，项目指令适合特定仓库的要求。记忆可以帮助不同对话延续上下文；关键项目规则应写入明确的项目说明。个性设置影响表达风格。Computer History 是可选的 macOS 功能，不属于 Windows 的配置步骤。可以在应用的个性化设置中查看可用选项。[官方来源](https://learn.chatgpt.com/docs/personalize) · [中文全文](zh-CN/personalize.zh-CN.md) · [英文原文](en/personalize.md)

## 3. 技能与插件（Skills & Plugins）

技能描述可重复执行的流程，也可以包含辅助资源。插件将可复用能力打包，并可通过 MCP 服务器连接工具。聚焦单项工作流程时可以使用技能；需要成套工具或外部服务连接时，可以考虑插件。Codex 能按请求匹配技能，也可以通过 `$` 提及指定技能。正式依赖某个流程前，先试用并检查结果。[官方来源](https://learn.chatgpt.com/docs/skills-and-plugins) · [中文全文](zh-CN/skills-and-plugins.zh-CN.md) · [英文原文](en/skills-and-plugins.md)

## 4. 权限（Permissions）

沙箱决定可访问哪些文件和网络资源，审批设置决定如何审核请求。自动审核本身不会扩大沙箱权限。在设置中启用某种模式，只会让它可以被选择。实际可用选项取决于本地配置和组织要求。官方建议多数工作从需要审批的模式开始。请查看当前任务实际显示的权限。[官方来源](https://learn.chatgpt.com/docs/permission-modes) · [中文全文](zh-CN/permission-modes.zh-CN.md) · [英文原文](en/permission-modes.md)

## 5. 在这个仓库中练习

以下练习是为本学习文件夹独立设计的建议。本次整理资料时没有执行这些练习。

### 练习 A：要求一个明确的交付物

把下面的请求发给 Codex：

```text
阅读 docs/en/prompting.md，创建 practice/my-notes.md，
列出学完后我应该能回答的五个问题。每题留出空白作答区，并链接到原文
对应小节。检查链接指向的小节标题确实存在于本地文件中。
```

检查保存的文件，再让它把其中一道题改得简单一些，另一道题改得更有挑战性，比较修改前后的版本。

### 练习 B：起草项目说明

```text
为这个学习仓库起草一份 AGENTS.md 建议稿。我的偏好是：用中文解释概念，
保留下载的官方英文文件，把我的练习放在 practice/。创建文件前先展示草稿。
```

判断这些偏好是否应该适用于这个文件夹里以后的每个任务。本资料包没有替你安装项目指令。

### 练习 C：找出可复用流程

先与 Codex 一起完成三份学习笔记，比较它们的结构。如果输入、步骤和输出反复相同，可以将这个流程描述为候选技能。第一版先只处理一种笔记。

### 练习 D：检查修改

```text
查看这个仓库的 Git 状态，解释哪些文件是新增的，哪些已跟踪文件发生了修改。
针对每项修改，告诉我如何检查。此次检查不要创建提交。
```

## 6. 这个文件夹的 Git 基础

本文件夹使用 Git 管理版本。初始化会创建仓库管理信息；它不会上传文件，也不会自动生成一个已保存的版本。当前分支和修改状态可以通过下方命令查看。

需要查看仓库时，在 `E:\myfile\use_codex` 中执行：

```powershell
git status
git diff
```

`git status` 列出未跟踪文件和修改状态。`git diff` 显示已跟踪文件中尚未暂存的修改，不会显示新增且未跟踪文件的内容；这些文件需要直接打开查看。

检查文件后，可以保存一个版本：

```powershell
git add .
git diff --cached --stat
git commit -m "Add local documentation and learning guides"
```

如果 Git 要求提供身份信息，请先为这个仓库配置你自己的姓名和邮箱，再提交。应使用你希望展示的真实配置；本次操作不会替你编造身份。本地提交不会把文件发布到 GitHub。
